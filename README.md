## ✨ Overview

Welcome to the digital frontier. This is a high-performance, aesthetically driven portfolio and admin ecosystem built with a focus on immersive UX, sci-fi aesthetics, and seamless state management.

### 🌌 Key Features
- **Modern Aesthetics**: Glassmorphism, glitch effects, and smooth micro-animations.
- **Dynamic Particles**: Interactive background system that responds to motion.
- **Admin Command Center**: A full-featured dashboard to manage projects, recognition, and outreach logs.
- **PWA & Offline Support**: Service worker integration for high-speed loading and offline accessibility.
- **SEO Optimized**: Meta-tags, Open Graph, and Twitter card integration for maximum reach.
- **Secure Dashboard**: Protected routes with session-based authentication.

## ⚙️ Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AstroSalik/Adnan-portfolio.git
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Configure Environment**:
   Create a `.env` file and add your admin secret:
   ```env
   VITE_ADMIN_PASSPHRASE=your_secret_here
   ```
4. **Run Development Server**:
   ```bash
   npm run dev
   ```
